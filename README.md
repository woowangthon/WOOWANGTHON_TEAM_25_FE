# WOOWANGTHON_TEAM_25_FE

현재 웹페이지의 사업자정보를 추출하고, 사업자 상태와 업체 정보 대조 결과를 표시하는 Chrome 확장 프로그램입니다.

## 기술 스택

- HTML / CSS / JavaScript
- Chrome Extensions Manifest V3

## 현재 구현 범위

- 현재 페이지에서 사업자등록번호, 상호, 대표자명 추출
- 사업자등록번호의 하이픈과 공백 제거
- 추출한 정보를 팝업에 표시
- 정보 미발견 및 페이지 접근 실패 안내
- 개발용 예시 데이터로 검사 결과와 불일치 근거 표시

실제 국세청·공정위·도메인 분석 API 연동은 예정되어 있습니다. 현재 검사 결과 영역은 가상 데이터이며 실제 조회 결과가 아닙니다.

## 로컬 실행 방법

1. 이 레포를 clone하거나 ZIP으로 다운로드합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json`이 있는 프로젝트 폴더를 선택합니다.
6. 쇼핑몰 페이지를 연 뒤 Chrome의 확장 프로그램 메뉴에서 우왕톤을 실행합니다.

코드를 수정한 뒤에는 파일을 저장하고, 확장 프로그램 관리 화면에서 우왕톤 카드의 새로고침 버튼을 누릅니다.

## 사용 방법

- 쇼핑몰 페이지에서 확장 프로그램을 열면 사업자정보를 추출합니다.
- 추출하지 못한 항목에는 **찾지 못함**을 표시합니다.
- **예시 결과 보기**를 누르면 개발용 검사 결과를 표시합니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 설정 및 권한 |
| `popup.html` | 팝업 화면과 스타일 |
| `popup.js` | 페이지 정보 추출, 팝업 표시, 예시 결과 렌더링 |

## 추출 데이터

| 필드 | 내용 |
|---|---|
| `businessNumber` | 하이픈과 공백을 제거한 사업자등록번호 |
| `companyName` | 페이지에 표시된 상호 |
| `representativeName` | 페이지에 표시된 대표자명 |

추출하지 못한 값은 `null`로 반환합니다. 이 데이터 형식은 API 연동 협의에 따라 조정될 수 있습니다.

## 확인할 항목

- 페이지에 표시된 사업자정보와 추출값이 일치하는지
- 대표자명에 전화번호나 개인정보담당자 정보가 함께 들어가지 않는지
- 사업자정보가 없는 페이지에서 안내가 표시되는지
- 접근할 수 없는 탭에서 오류 안내가 표시되는지

## 현재 한계

- 텍스트 표기를 기준으로 추출하므로 사이트 구조에 따라 일부 항목을 찾지 못하거나 잘못 추출할 수 있습니다.
- 추출값은 페이지에 표시된 정보이며, 진위 확인은 API 연동 후 수행합니다.
- 플랫폼 페이지 하단에서 추출한 정보는 플랫폼 운영업체의 정보일 수 있습니다.
