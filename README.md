# WOOWANGTHON_TEAM_25_FE

현재 웹페이지에 표시된 사업자정보를 추출하고, 국세청 사업자 상태와 공정거래위원회 등록 정보 대조 결과를 보여주는 Chrome 확장 프로그램입니다. 팝업에서 종합 판정, 위험 점수, 판정 근거를 확인할 수 있습니다.

## 기술 스택

- HTML / CSS / JavaScript
- Chrome Extensions Manifest V3

## 현재 구현 범위

- 현재 페이지의 사업자등록번호, 상호, 대표자명, 사업장 주소 추출
- 한글 및 영문 라벨과 여러 줄에 걸친 대표자 표기 처리
- 사업자등록번호 형식 확인과 미발견·형식 오류 안내
- 페이지 URL과 추출한 사업자정보를 백엔드에 전송
- 국세청 사업자 상태 조회 및 공정위 등록 정보 대조 결과 표시
- 항목별 일치·불일치·확인 불가·대조 생략 결과 표시
- 대표자명 불일치 시 페이지 표기와 공정위 등록 이름 표시
- 종합 판정, 총 위험 점수, 위험 근거 목록 표시
- 페이지 접근 실패 및 백엔드 요청 실패 안내
- 팝업을 열지 않아도 사이트 방문을 감지하고 서비스 워커 콘솔에 도메인 출력

## 로컬 실행 방법

### 1. 백엔드 실행

실제 조회를 하려면 BE 레포의 로컬 서버가 필요합니다. BE 레포의 README에 따라 환경을 설정한 뒤 `127.0.0.1:8000`에서 서버를 실행합니다. FE의 조회 경로는 `http://127.0.0.1:8000/api/v1/scan/`입니다.

### 2. Chrome 확장 프로그램 로드

1. 이 레포를 clone하거나 ZIP으로 다운로드한 뒤 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json`이 있는 프로젝트 폴더를 선택합니다.
6. 검사할 쇼핑몰을 열고 Chrome 확장 프로그램 메뉴에서 **우왕톤 사업자정보 확인**을 실행합니다.

코드를 수정한 뒤에는 파일을 저장하고 `chrome://extensions`에서 확장 프로그램 카드의 새로고침 버튼을 누릅니다.

## 사용 방법

1. 쇼핑몰 페이지에서 확장 프로그램 팝업을 엽니다.
2. 팝업 상단에서 페이지에서 읽은 사업자등록번호, 상호, 대표자명을 확인합니다. 추출하지 못한 항목은 **찾지 못함**으로 표시합니다.
3. **검사 결과**에서 국세청 사업자 상태, 공정위 대조 결과, 종합 판정과 근거를 확인합니다.

사업자등록번호가 없거나 형식이 올바르지 않아도 페이지 URL과 추출된 정보는 전송합니다. 백엔드는 사업자등록번호가 없으면 국세청 조회를 생략하며, 상호가 있으면 공정위 상호 검색을 시도합니다.

## 백엔드 연동

팝업을 열면 `POST /api/v1/scan/`을 호출합니다.

| 요청 필드 | 설명 |
| --- | --- |
| `url` | 검사 대상 페이지 URL |
| `business_info.business_number` | 유효한 번호는 `000-00-00000` 형식으로 전송. 누락 또는 형식 오류는 빈 문자열(`""`)로 전송 |
| `business_info.business_name` | 페이지에서 추출한 상호. 미발견 시 `null` |
| `business_info.representative_name` | 페이지에서 추출한 대표자명. 미발견 시 `null` |
| `business_info.address` | 페이지에서 추출한 사업장 주소. 미발견 시 빈 문자열(`""`) |

팝업은 응답의 `analyses.nts`, `analyses.ftc`, `verdict`, `risk_score`, `risk_factors`를 사용해 검사 결과를 표시합니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 프로그램 설정, 권한, 팝업 및 서비스 워커 등록 |
| `popup.html` | 사업자정보와 검사 결과를 표시하는 화면 및 스타일 |
| `popup.js` | 사업자정보 추출, 백엔드 요청, 검사 결과 표시 |
| `background.js` | HTTP·HTTPS 페이지의 방문을 감지하고 서비스 워커 콘솔에 도메인 출력 |

## 동작 확인

- **사업자정보 추출**  
  팝업 상단의 값이 페이지에 표시된 정보와 일치하는지 확인합니다. 대표자명에 주소가 붙거나 주소에 연락처가 섞이지 않는지도 확인합니다.
- **API 요청과 응답**  
  팝업 안에서 우클릭 후 **검사**를 열고, Network 탭의 `scan/` 요청에서 **Payload**와 **Response**를 확인합니다.
- **사이트 방문 감지**  
  `chrome://extensions`에서 **서비스 워커** 검사 창을 엽니다. 사이트에 접속한 뒤 Console에 `[우왕톤] 사이트 방문 감지`와 도메인이 출력되는지 확인합니다.

## 현재 한계

- 페이지 텍스트를 기준으로 추출하므로 사이트 구조와 표기 방식에 따라 일부 값을 놓치거나 잘못 읽을 수 있습니다.
- 플랫폼 페이지 하단에서 추출한 정보는 개별 판매자 대신 플랫폼 운영사 정보일 수 있습니다.
- 브랜드명과 공정위 등록 상호가 다르면 상호 불일치로 표시될 수 있습니다. 등록 대표자명이 마스킹된 경우에는 대조가 어려울 수 있습니다.
- 위험 점수와 종합 판정은 백엔드가 수행한 검사 항목을 기준으로 합니다. 이 결과만으로 사이트의 안전이나 사기 여부를 확정할 수는 없습니다.
